= pact-avro-plugin

A https://docs.pact.io[Pact] plugin for testing messages serialised with
https://avro.apache.org/docs[Apache Avro], using the Pact contract testing framework.

NOTE: Unlike the rest of the org's repos, this isn't an accessibility/TTS project -- it's a
general-purpose contract-testing plugin. Worth deciding whether it belongs in the ZirekHQ docs
site at all, or should stay out of the org-wide aggregation.

Docs spike: this component is aggregated into the org-wide
https://zirekhq.github.io[ZirekHQ documentation site].
