= Differences from 0.0.x

Version 0.1.0 replaces the JVM plugin with a native binary. No JVM is needed to run the plugin.

== Regenerated pacts differ once

Pacts generated by 0.1.0 embed schema text that differs from 0.0.x output (no `logicalType` attributes, different key order), so the `schemaKey` changes. Regenerate and republish your consumer pacts after upgrading. Verifying pacts generated by 0.0.x still works, because the schema travels inside the pact.

== Map field encoding order

Avro `map` fields with two or more entries encode their entries in an unspecified order that can change between runs. A pact containing such a field can show as changed on every publish.

== Versioning

Releases follow semantic versioning. While the major version is 0, a breaking change to pact content or behavior bumps the minor version.
